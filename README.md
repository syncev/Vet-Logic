## Instalación (copien esto en la terminal y ejecuten)

1. Crear un entorno virtual:

```bash
python -m venv .venv
source .venv/bin/activate
```

2. Instalar dependencias:

```bash
python -m pip install -r requirements.txt
```

3. Ejecutar la app con el boton de play o con este comando:

```bash
python main.py
```
